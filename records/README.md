# New run records

The controller creates separate test/pilot/main participant and run directories here.
No records from the original ZIP are reused. Keep names and consent files separate.
`main_data.csv` is the analysis table: the controller records the final measures itself, and video
is not coded. An optional OBS recording may be kept as a backup for unusual trials.
Retain the whole run folder (`main_data.csv`, `events.csv`, `trials_aux.csv`, `session.json`).
NASA-TLX remains in the separate Google Forms survey; join it to `main_data.csv` by participant
code and condition.
See ../DATA_DICTIONARY.md and ../README.md for definitions, session guards and recovery rules.
